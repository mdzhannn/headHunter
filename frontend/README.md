# HeadHunter — Frontend

Admin-панель для управления пользователями, резюме и вакансиями.

## Стек

- React 18 + TypeScript
- Vite 5
- Tailwind CSS
- DM Sans (шрифт)

## Структура

```
src/
├── api/
│   └── index.ts          # Все API-запросы к бэкенду
├── components/
│   └── ui.tsx            # Переиспользуемые UI компоненты
├── pages/
│   ├── UsersPage.tsx     # CRUD пользователей + блокировка
│   ├── ResumesPage.tsx   # CRUD резюме + верификация
│   ├── VacanciesPage.tsx # CRUD вакансий + верификация
│   └── EmailPage.tsx     # Уведомления
├── types/
│   └── index.ts          # TypeScript интерфейсы
├── App.tsx               # Layout с сайдбаром и роутингом
└── main.tsx              # Точка входа
```

## Запуск

```bash
npm install
npm run dev
```

Бэкенд должен быть доступен на `http://localhost:8080`.  
Vite автоматически проксирует `/api`, `/resume`, `/vacancy`, `/email` на бэкенд.

## Возможности

- **Пользователи**: создание, редактирование, удаление, блокировка/разблокировка
- **Резюме**: создание, редактирование, удаление, верификация, фильтр "На проверке"
- **Вакансии**: создание, редактирование, удаление, верификация, фильтр "На проверке"
- **Email**: отправка сообщений, кодов, проверка кодов
- Модальные окна для форм
- Toast-уведомления об успехе/ошибке
- Спиннер загрузки и пустые состояния
